Records
What each record contains.
Every entity record includes a canonical name, entity type, core facts with per-fact source citations, a disambiguation statement, and sameAs links to corresponding records on authoritative external platforms. Verified records include domain ownership confirmation. Full Profile records extend to relationships, products, services, and leadership.

Schema.org JSON-LD
Machine-readable structured data. Queryable by AI systems, crawlers, and RAG pipelines directly.
Open API
REST endpoint at /api/entity/{slug}. No key required. Returns full record with sameAs, relationships, and dateModified.
llms.txt
Verified entities are included in the registry llms.txt feed for AI agent discovery.
API
Open API. No auth.
The registry API is publicly accessible without authentication. Queries return Schema.org JSON-LD with sameAs cross-links, per-fact source citations, relationship edges, and a timestamped modification date.

Listing
Submitting an entity.
Any organization, person, or product may be submitted for review. Basic records are created from public sources. Domain verification is available to organizations that control the associated domain. Extended records with relationship graphs and full JSON-LD are available under the Full Profile tier.

Entities.org does not independently fact-check listed data. Records are formatted from public sources. Entities that cannot be substantiated will not be published.
